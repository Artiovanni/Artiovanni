## 👋 Sobre mim

Sou estudante de **Ciência de Dados na FIAP** e trabalho com dados, cloud e IA.

Eu gosto de **destrinchar o conhecimento**. Quando aparece algo novo, não paro no “funciona”: vou atrás de por que existe, como foi pensado e onde realmente faz diferença.

Cada coisa que exploro vira uma **habilidade que eu construo para mim mesmo**. Organizo o que aprendi, comparo com o que o mercado já usa como padrão e, a partir dessa base sólida, **procuro jeitos novos de fazer melhor.**

É assim que eu encaro dados: entender a fundo, padronizar com o que funciona e **inovar em cima disso.**

